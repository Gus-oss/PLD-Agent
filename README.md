   # PLD-Agent

   Sistema multiagente de IA que monitorea un modelo de detección de lavado de dinero,
   detecta cuándo pierde eficacia y diagnostica la causa.
   Tesis de la Maestría en Ciencia de Datos, UANL.

   ## Configuración
   1. Copiar `.env.example` a `.env` con tus llaves.
   2. Instala dependencias con `uv sync`.
